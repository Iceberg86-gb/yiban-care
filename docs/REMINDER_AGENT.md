# 自然语言计划 Agent 与语音提醒

入口：[计划助手](http://localhost:4317/?view=plans)。这是有伴产品内的功能，不创建 Codex 定时任务。

## 可以直接试的表达

- 每天晚上八点提醒周伯记录用药。
- 明天上午九点提醒我整理就诊摘要。
- 每周三下午三点半提醒我查看照护记录。
- 工作日上午九点提醒我喝水。
- 一分钟后提醒我记录心情。

接收人：“周伯／老人／患者”对应老人端，“我／家属／周宁”对应家属端。当前聊天入口由家属操作，身份仍为演示身份。

时间不完整时会追问。例如“每天八点提醒我喝水”会询问时段，接着说“晚上八点”即可。生成草稿后，也可以说“改成晚上九点”。计划启用前，可以直接编辑草稿中的事项、接收人、频率和时间。

支持一次性、每天、每周和工作日提醒；一条请求生成一条计划。启用后的计划通过对应卡片修改、暂停、恢复或取消。复杂表达、多个时间或缺失信息可能需要继续补充，不应把本地解析当成通用语言模型。

## Agent 实际接入状态

复用已有 `.env` 配置：

```dotenv
QIANFAN_API_KEY=填写你的千帆服务端凭证
QIANFAN_MODEL=填写账号支持工具调用的模型ID
```

配置后重启本地服务。模型将通过千帆的文本生成／工具调用接口理解计划。可用工具限定为：

- `propose_reminder`：返回待启用草稿，不直接启动计时。
- `list_reminders`：读取当前有效计划。
- `clarify_reminder`：询问一项缺失或有歧义的信息。

工具参数还会经过服务端验证。未知工具被拒绝，过期日期、无效星期和相互冲突的时间参数不能启用。只有用户在草稿卡点击启用后，服务器才保存计划。

未配置凭证、模型请求失败或返回不可用参数时，使用明确标记的「本地简易解析」。请求、来源和实际工具结果显示在聊天和执行记录中，不能把本地模式说成已调用文心。真实账号权限、模型工具支持与输出质量需要凭证就绪后实际联调。

## 到点提醒与语音

- 服务端按北京时间保存下一次触发时间，前端刷新不会重置。
- 一次性提醒触发后，计划显示「已触发」，不表示事项已完成。
- 每天／每周提醒自动计算下一次；同一个触发点不会因重复检查而重复创建。
- 点「知道了」仅确认这条提醒；点「5 分钟后」只延后本次，原计划频率保持不变。
- 老人端与家属端按接收人分别展示。紧急照护事件优先，普通计划的自动语音暂缓。
- 修改、暂停或取消计划，会明确停止尚未处理的旧提醒，保留历史记录。
- 本地服务重启后恢复计划；逾期多次的重复计划只补一条逾期提示，并推进下一次，避免批量补响。

点击「开启语音提醒」后，当前设备通过统一语音服务播报，沿用老人偏好中的音色、语速和音量。详见[语音系统](VOICE_SYSTEM.md)。开启状态按设备与接收角色保存；同一浏览器用播放标记尽量减少多个页面重复自动播报。可手动点击「读给我听」重播。回执分为 playing／completed／failed，播放完成不证明用户听到或理解。

语音输入使用浏览器 SpeechRecognition：支持情况因浏览器而异，可能依赖联网服务。点击语音输入后由浏览器请求麦克风授权，听写内容可修改后再发送；不支持时可以直接打字。当前没有接入百度 RTC 实时音频链路。

**本地服务需要运行，页面需要保持打开，才能即时展示和播报。** 关闭页面后重开可查看未确认提醒；设备睡眠、浏览器音频限制或声音关闭可能影响播报。没有操作系统后台推送、真实短信或真实医疗联络。

用药提醒仅提示核对既定医嘱和记录，既不设置药物剂量，也不因确认提醒而登记已服药。陈旧的用药提醒显示为逾期，提示先核对当前安排。

## 验收路径

1. 在计划助手输入「一分钟后提醒周伯记录心情」。
2. 核对草稿并启用，打开老人端。
3. 等待一分钟，或在演示控制台推进 60 秒（推进会影响本轮所有服务端计时）。
4. 老人端出现计划提醒，测试手动播报、延后和确认。
5. 查看计划助手中的提醒历史与实际执行记录。

测试文件 `tests/reminders.test.js` 覆盖自然语言、日期时区、草稿启用、幂等、暂停取消、延后、重启、过期补记、模型故障、迟到结果和接入来源。模型相关测试使用构造响应，不代表真实千帆账号已验证。

## 实现位置

- `server/planner-agent.js`：千帆计划 Agent、受控工具与本地降级。
- `server/reminder-language.js`：明确中文表达的本地解析与追问。
- `server/plans.js`：草稿启用、计划管理、触发、回执和恢复。
- `shared/plans.js`：时区日期计算、重复规则、提醒文案。
- `src/ReminderAgent.jsx`、`src/reminders.css`：聊天、草稿、计划卡、语音与双端提醒。

API：`POST /api/agent/plan`、`POST /api/reminders/activate`、`POST /api/reminders/change`、`POST /api/reminders/action`、`POST /api/reminders/voice`。数据纳入现有本地 JSON 与完整场次导出；演示复位会清空提醒计划、聊天和历史。

参考：[千帆工具调用](https://cloud.baidu.com/doc/qianfan-docs/s/xm95lyys5)、[Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API)、[SpeechSynthesis.speak](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/speak)。
