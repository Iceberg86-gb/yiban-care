# 手机双端演示

默认访问 `/` 为手机演示舞台，`/?view=elder` 直接进入患者端。原完整工作台保留在 `/?view=dashboard`，也可从桌面右上角“演示说明”打开。

## 页面

- 患者端：小安聊天、情境找物、语音回放、浏览器语音输入（支持时）、用药提醒、家人求助、异常确认。
- 看护端：守护、地图、看板、我的四个 Tab。用药记录是看板的独立模块，详情保留来源与核实过程。
- 我的：设备添加与状态、人员和三级联系链、联络计时、路线范围、作息、用药方案、饮食饮水、危险行为敏感度、隐私、语音偏好及三层知识库。
- 手机窗口之外：角色切换、双端对照、场景切换、暂停／继续、重置。真实手机宽度下全屏展示，底部保留紧凑的演示工具。

## 推荐操作

1. 点“日常陪伴”，点击找眼镜的示例问题或打字，查看回复与播放按钮。聊天为本地情境回复。
2. 点“用药提醒”，患者点“我知道了”，再点“我已服用，请家人核实”。切换看护端，在“看板 → 用药记录与依据”核实。仅收到提醒不会写入服药记录。
3. 点“跌倒守护”。前4秒行走，4–5.7秒失衡倒地，6.5秒触发疑似跌倒。本人确认窗口采用家庭配置（默认8秒演示时间）。可切换患者端回应，或等待升级后在看护端接手、记录到场、填写结果并保存。
4. 点“路线偏离”。虚构定位先沿常用路线移动，再连续偏离常用路线，并最终越出安全区域。确认、家人接手、找到老人、填写结果串成同一事件。
5. “我的”中编辑配置后刷新，已保存内容保留。使用“电子血压计”等设备类型可以演示离线状态。

## 时钟、数据与边界

`/api/mobile/action` 驱动服务端场景，双端使用相同 SSE 状态。暂停冻结本地演示时钟及其所有计时任务；继续时恢复时钟连续性。刷新或服务重启保留暂停状态。推进旧演示时钟前需先继续。

重置／切换场景只结束当前手机场景的未完成事件并撤回其未完成提醒，不重置家庭设置，不删除已确认的日常记录。同类的普通工作台事件与手机场景分开。重置事件明确记为“演示已重置”，不记录为安全结论。

照片是 AI 生成资产，跌倒为位图动作模拟；地图沿用本地虚构社区几何图，不是实际 GPS 或摄像头推理。通知、电话和对讲为应用内模拟。语音播放依赖浏览器系统音色；方言保存为偏好，不能保证终端支持。作息和饮水间隔保存为个人偏好，饮水定时提醒仍通过完整工作台的计划助手单独启用。

“载入日常样例”使用原有样例接口，仅在无日常记录时可用，避免混入已有记录。看板统计使用所选周期、实际记录与已到期的缺失时段，区分计划、本人报告、家属核实和待核实。

## 第二轮优化

- 看板的用药概览移至周期选择之后，摘要直接引用有记录的睡眠、心情和行为天数。
- 守护首页前置用药待办，并显示设备最后更新时间；设备离线或数据过旧时展示待更新状态。
- 日常问候为青绿，用药提醒为琥珀，紧急确认保持红色。患者端新增固定的一键通知家人按钮。
- 语音默认点按开始／结束，可在“我的 → 老人偏好”切换为按住模式；称呼用于下一次问候和新回复。
- 饮水设置可直接启用白天提醒。提醒时点由起床、就寝和间隔计算，保存更新而不重复创建；关闭撤回未处理提醒。“保存并体验一条提醒”创建一次性体验消息并切换患者端。
- 新增失衡伸手、侧卧地面两张透明人物资产，使用同一场景时钟驱动姿态切换。

点击页面底部“完整演示”，服务端依次演示：0–15秒聊天、15–39秒用药、39–64秒跌倒、64–90秒路线偏离。角色、Tab和详情面板自动切换，顶部显示讲解与进度。暂停／继续与刷新、服务重启共用同一时钟。过程中仍可手动操作；下一脚本节点恢复自动展示。

自动核实明确标为脚本模拟；其用药记录存入本轮演示数据，不写入日常记录。演示事件以 `demo_completed` 结束，不作为真实核实结论。切换独立场景或重置会退出完整演示。若演示中关闭跌倒规则，脚本暂停并提示开启，不改写家庭设置。

本轮新增自动演示、暂停/重启边界、饮水调度、称呼、配置原子性及自定义地图范围测试。全套测试共122项。
