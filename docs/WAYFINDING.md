# 找路演示与小安语音

页面底部选择“找路演示”，患者端会出现“帮我找到去超市发的路”的对话，小安先确认是否为上地五街的超市发。确认后才显示三步路线。可点击“我到路口了”“我已右转”“我找到了”推进，固定操作区也提供当前步骤按钮。支持更换为回家或社区服务站，以及停止找路。

此场景采用固定路线数据，不读取真实GPS、不计算真实道路路径。每张路线卡都标明情境演示。到达结果来自用户按钮或文字确认，并非独立定位验证。未知目的地先给出选择，不编造医院等地点的路线。

## 语音行为

- 小安的新聊天应答自动加入播放队列，包括目的地确认、路线总览、每步提醒、到达确认；患者端提醒和完整演示的相关应答也使用同一音频播放机制。
- “播放这段话”可重播；编号旁的播放按钮可单独读某一步。暂停、关闭语音或切换场景会停止旧播放，迟到的音频请求不会重新出声。
- 长回复分段合成和顺序播放。当前客户端还包含下一段预取及单页播放归属，避免同一页面多个语音入口同时发声。
- 如果浏览器阻止自动播放，会显示开启声音的按钮；由用户点击后继续，不假称已经播放。
- 当前未配置百度凭证时，macOS服务端使用Tingting等本机中文声音，生成可播放音频。界面显示实际使用的声音来源。

## 百度语音配置

在 `.env` 填写 `BAIDU_TTS_API_KEY`、`BAIDU_TTS_SECRET_KEY`，按账户权限选择 `BAIDU_TTS_SPEAKER`，然后重启服务。凭证仅在服务端使用。`LOCAL_TTS_VOICE` 控制macOS备用声音。

服务端使用OAuth获取token，再请求短文本合成；收到音频响应后才标为百度合成成功。接口和鉴权依据：[百度短文本合成文档](https://ai.baidu.com/ai-doc/SPEECH/mlbxh7xie)、[语音鉴权文档](https://ai.baidu.com/ai-doc/SPEECH/Em8snejw1)。百度不可用时会明确回退，不将本机声音标记为百度音色。

本机生成使用临时目录，完成后删除文本和音频临时文件。重复语句可命中有限大小的内存缓存。音频接口受现有家庭访问控制保护，并校验当前runId与文本长度。

## 验证

单元测试覆盖确认前不生成路线、目的地更换、过期操作、到达确认、未知目的地、语音缓存、百度响应类型、静音后迟到音频、播放队列及自动播放受限时恢复。

浏览器已验证整段指路音频可播放：WAV解码readyState=4，播放时间实际推进；初版整段指路音频约18.9秒，到达回应约7.2秒。生成的验证WAV为22050Hz单声道且包含非零采样，未使用静音占位。最新播放模块按语句分段，单段时长会不同。

截图与检查记录在 `output/wayfinding-qa/`。真实百度账号权限与实际定位导航不属于本次已验证范围。
