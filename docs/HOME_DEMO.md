# 四 Tab 演示与验收

## 3分钟建议路径

| 时段      | 页面与操作                                    | 讲述重点                                                                                   |
| --------- | --------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 0:00-0:20 | 监控页，查看画面、体征与动作计划              | “Agent值守，人做决策”；画面和设备数据标为模拟                                              |
| 0:20-1:25 | 点“跌倒”，等待8秒确认，或在演示控制台推进时间 | 一级成员全部立即联络，首次联络30秒后二级追加，60秒后急救信息前置；无人接手与未送达分别记录 |
| 1:25-1:55 | 报告页，查看个人基线与AI解读                  | 活动、夜间与用药信号组合为可核实的问题；每项有样本数与资料来源                             |
| 1:55-2:25 | 我的页，展示设备、紧急联系链与个人规则        | 触达对象与规则是可配置前提；小度、手环、智能屏、手机分别标记模拟状态                       |
| 2:25-3:00 | 地图页，播放路线偏离情境                      | 位置质量、围栏、路线偏离与夜间规则分别处理，避免把单次漂移当作走失结论                     |

演示时钟仍会推进本轮所有事件与计划计时，不修改已保存的截止时间。主监控情境使用新的8/30/60秒策略；旧演示控制台的原有场景保留45秒确认，便于回归对比。

## 用药动作闭环

1. 监控页点击“开始用药演示”，一秒后进入模拟用药任务。
2. 点击“模拟动作链”：记录取药、送口、饮水的预设证据，状态为候选。
3. 家属点击“确认服用”后才写入服药记录。单击普通提醒的“知道了”不代替核实。
4. 未核实则按配置重复最多3次，随后升级给家属。
5. 对同一用药项再次模拟动作链，会触发疑似重复服药核实与智能屏模拟提示；不同用药项不混合。

动作链不能证明实际吞服。当前无真实摄像头、药盒或吞咽检测。

## 误报与个体化

监控页启动“弯腰误报”情境，接手并以“误报＋弯腰拾物原因”结案。在“我的 → 分层知识库”中可查看该条纠错，手动应用到演示规则后再次播放弯腰场景，形成观察记录而不重复报警。这个结果仅说明规则链路可运行，不代表真实模型已训练或真实误报率下降。

## 周期与临时报告

默认每周一09:00保存周报快照，可在“我的”切换为每月1日09:00月报。新异常会自动保存临时报告；这些快照与生成时的数据绑定，当前报告仍可随时查看。周期规则由本地服务执行，外部Push和真实模型自动解读需要后续接入与授权。

## 病历、医嘱与PDF

在“报告 → 病历与医嘱”上传或粘贴文字。可用“填入虚构示例”完成现场演示。候选字段包含诊断、过敏、药名、剂量原文、频率、明确时间、复诊日期时间和指标原文。

家属核对后，明确的每日用药时点及未来复诊时间可以生成提醒草稿，随后在计划助手逐条启用。频率、日期或时间不明确时不猜测。扫描件不自动OCR，仍可对照原文件转录。

PDF默认包含模拟监测数据，显著标明演示来源。可在就医资料页导出最新的有伴就医包。实际导出根据资料量排版，较多用药和事件会节选，并提示补充完整清单。

## 隐私与安全实际边界

- 当前运行存档和上传原文件用AES-256-GCM静态加密，密钥位于同机权限文件。不是端到端加密。
- 家庭访问口令为可选设置 `APP_ACCESS_CODE`；未设置时保持本地演示访问，不宣称真实成员鉴权。
- 设置口令后，家庭API需要会话；医生分享链接只提供选定PDF快照，24小时过期且可撤销。真实多成员独立账号、机构授权和HTTPS部署仍需工程化。
- 摄像头敏感空间布点被拦截。夜间片段策略、范围确认和知情告知均有配置与记录；当前没有真实连续视频采集。
- 真实120、电话、Push和免打扰穿透均未接入；页面按钮只模拟动作与回执。

评分、收费、SOS物理入口和B端协同模式仍保留为产品决策，不因完成demo自动定案。
