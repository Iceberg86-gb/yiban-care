# 本地验收记录

验收日期：2026-09-12。此记录仅覆盖本地比赛 demo，不代表真实老人、真实传感器或百度生产账号的接入验证。

## 自动化验证

`npm run check` 执行 Node 测试与 Vite 构建。新增四Tab监控方案后共 107 个测试，覆盖：

- 确认超时、明确求助立即升级、否认求助保留截止时间。
- 收音失败与回应未知，终端播放和收音来源分开记录。
- 送达不自动接手，医疗接单不替代家人接手。
- 备用联络、接手后的进展检查、人工进展更新。
- 并发接手版本冲突、来源事件去重、重复任务幂等。
- 未知送达状态核查，不盲目重发。
- 结案记录、医疗任务明确处理、责任移交回执、有效结案枚举。
- 文件持久化、服务重启到期恢复、保存失败回滚。
- 复位隔离旧消息、递增场次序号、迟到模型响应丢弃。
- 慢表达时间序列与确认联系家人。
- 无凭证模板、模拟模型工具响应、工具白名单、故障注入与模型失败降级。
- 患者简单记录、家属追加、身份选项校验、原始记录与重要历史保留。
- 普通记录静默、用药计划到期与跨午夜检查、漏服与未知区分、按窗口去重。
- 明显变化与突发变化分级、较轻新报告保留原高优先级、结案后的新异常再次提醒。
- 多事件按优先级展示，结案一个后继续跟进其他未处理风险。
- 历史补记、样本隔离、覆盖与均值仅计算已知数据、就诊摘要保留家属补充。
- 中文提醒请求、时段追问、草稿修改、启用与去重、一次／每日／每周触发、延后、暂停取消、恢复与版本校验。
- 提醒确认不代表服药、真实语音回调来源、逾期只补一条、模型工具白名单、模型故障和迟到响应隔离。
- 8/30/60秒多级联络、三级成员不可接手、急救提示不冒充实际呼叫、敏感布点拦截、个体纠错仅演示应用。
- 用药动作候选与家属核实、三次未确认升级、同一用药项重复候选、取消后停止追问。
- 轨迹回放、围栏编辑、夜间联络、离腕断连窗口、历史轨迹、个人基线样本不足处理。
- 病历原文提取、频率与时间不猜测、核对后生成医嘱草稿、加密存档/原件恢复、访问口令和医生分享范围。

模型测试使用构造响应，没有消耗真实千帆额度。安装时 npm audit 报告 0 个已知依赖漏洞；这不是完整安全审计。

## 浏览器验收

- 本地工作台正常加载，正常状态和疑似跌倒状态均经过截图检查。
- 老人端点击需要帮助，工作台出现联络任务；家人接手和进展更新同步到老人端。
- 生成本地模板交接卡，保留结构化事实、未知信息与来源标签。
- 人工填写核实结果并处理模拟医疗任务后结案；页面刷新可恢复结果。
- 演示控制台复位后事件数归零，可以再次启动情境。
- 慢表达展示完整“我想……找一下……我女儿。”后出现确认问题。
- 位置异常展示虚构社区图、模拟轨迹、位置来源和采集时间。
- 手机断点检查：390 CSS 像素视口无页面横向溢出；工作台中的老人端 iframe 约 390 像素宽，按钮交互与同步已验证。
- 页面内提供原始架构图、全栈任务映射、接入说明与答辩指南。
- 新增日常照护：患者点击已服药、没睡好后家属端同步；家属追加说明保留患者原始记录；趋势图展示空缺、有效记录和已知样本数。
- 明显变化补记后出现家属优先提醒，可进入原照护事件；详情不伪造位置。多日睡眠／心情波动进入静默关注。
- 患者一键记录在约 390 像素的实际 iframe 中完成操作与截图检查，三个主选项清晰显示。
