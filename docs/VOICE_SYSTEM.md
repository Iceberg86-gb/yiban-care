# 语音系统

聊天、找路、计划提醒、老人端“读给我听”和家属试听统一使用 `/api/speech` 与 `CompanionAudio`。同一页面只保留一个正在播报的播放器；手动试听或新的优先内容会停止旧内容。

## 音色与试听

在看护端「我的 → 老人偏好」选择声音、日常聊天语气、语速、音量，点击「试听这段问候」，满意后保存。试听应用尚未保存的偏好，关闭设置会停止试听。音量为零时保持静音。

- 小安推荐：服务端默认音色；有百度凭证时默认 `4197`，无凭证时使用 macOS 中文合成。
- 度沁遥 `4197`：知性女声，大模型音库。
- 度怀安 `4195`：磁性男声，大模型音库。
- 本机中文：直接使用服务所在 Mac 的中文声音，不访问百度。

两种大模型音色支持平和 `neutral` 与轻快 `happy`。日常聊天可选择轻快；自动提醒、找路、求助与手动重播使用平和语气。方言仅保存偏好，不会改变合成语言。

## 百度配置

复制 `.env.example` 为 `.env`，设置 `BAIDU_TTS_API_KEY`、`BAIDU_TTS_SECRET_KEY`，在百度控制台开通对应音库权限后重启服务。密钥只在服务端读取，不要提交到版本库。

`BAIDU_TTS_SPEAKER=4197` 为推荐默认值；可设 `4195`。若账号仅开通基础音库，可设 `0`，基础音库不发送情感标签。显式选择的音色会覆盖服务端默认值。

- [百度短文本合成 API](https://cloud.baidu.com/doc/SPEECH/s/mlbxh7xie)
- [百度情感标签与支持音色](https://ai.baidu.com/support/news?action=detail&id=3267)

当前无凭证时只有本机声音可试听。百度调用失败会回退到本机，页面明确显示回退提示，不将其标为百度声音。Linux/Windows 服务端需配置百度，当前未提供这些系统的离线合成适配。

## 连贯性与可靠性

- 按完整句意分段，第一句先准备，后续段落最多 90 字；保留时间、药量、名字和原有顺序，不让模型改写用药信息。
- 播放当前段时提前准备一段，最多预加载一段，降低句间请求等待。此版本为分段 HTTP 合成与预加载，并非 WebSocket 流式合成。
- 服务端最多同时执行两个合成任务、最多保留 16 个待处理任务；相同文本、音色、语气、语速的请求合并，并使用 16 MiB 内存音频缓存。
- 百度失败后按音色退避 20 秒，避免每句重复等待超时。临时回退音频不进入缓存，恢复后相同文本可以重新使用百度声音。
- 停止、换音色、切换演示或复位时取消前端请求并丢弃迟到结果、释放音频 URL。服务器可能完成已经开始的合成并缓存成功结果，但旧内容不会再播放。
- 自动播放被浏览器拦截时保留待播内容，点击继续即可重试。
- 提醒回执在实际开始播放、整条消息结束、失败时上报；中途取消不会上报完成。回执记录 `source: server_tts` 与实际 `provider`，旧 `browser_tts` 回执保持兼容。完成播报不等于老人已听到、理解或执行提醒。

## 检查

`npm run check` 运行回归测试和生产构建。语音回归覆盖预加载、取消、暂停恢复、播放器互斥、回执完整性、音色校验、缓存隔离、限流、鉴权复用与故障恢复。

本次在无百度凭证环境验证了真实本机 WAV 生成和浏览器试听。百度请求参数、音色切换及故障恢复使用模拟上游验证；大模型真实音质、音库权限和云端延迟需配置后试听评估。
