# 有伴 · 多模态照护演示

面向比赛答辩的可运行 Web demo。以“芯片—框架—模型—应用”为技术叙事，以“异常发现—确认—升级—接手—跟进—结案”为可操作主线。

## 服务器部署交接

给负责部署的朋友：请从 [服务器部署与交接说明](docs/DEPLOYMENT.md) 开始。仓库包含 Dockerfile、Docker Compose 和 Nginx 模板，覆盖 Python PDF 依赖、中文字体、数据持久化、HTTPS、更新与备份。部署为单实例受控演示。

最新主入口为 **手机双端演示**：患者端是小安聊天，看护端为 **守护 / 地图 / 看板 / 我的**。详见 [手机演示说明](docs/MOBILE_DEMO.md)。页面底部的“完整演示”可自动播放90秒双端照护流程；饮水设置可直接启用患者端提醒。原完整工作台保留在 `/?view=dashboard`。完整需求对照见 [功能比对与实现边界](docs/FEATURE_COMPARISON.md)。日记、Agent计划、事件工作台和老人端保留为上下文工具。

## 一分钟运行

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开 [手机双端演示](http://localhost:4317)，可在页面上切换角色或打开双端对照。独立患者窗口打开 [老人端](http://localhost:4317/?view=elder)。两端订阅同一个服务端事件状态。

答辩前建议构建后运行，字体、图标、示意图和参考架构图全部从本地加载：

```sh
npm run build
npm start
```

默认只监听本机 `127.0.0.1:4317`。不要同时运行两个服务实例。

## 配置百度服务

```sh
cp .env.example .env
```

编辑 `.env` 后重启服务：

| 配置                   | 用途                                                                  |
| ---------------------- | --------------------------------------------------------------------- |
| `QIANFAN_API_KEY`      | 千帆服务端 API Key；不会发给前端                                      |
| `QIANFAN_MODEL`        | 当前账号可用模型 ID；示例为 `ernie-4.5-turbo-128k`                    |
| `BAIDU_MAP_BROWSER_AK` | 百度地图浏览器类型 AK；按 SDK 机制提供给浏览器，需配置 Referer 白名单 |
| `PORT`                 | 默认 `4317`                                                           |
| `HOST`                 | 默认 `127.0.0.1`；可信局域网手机演示可改为 `0.0.0.0`                  |
| `APP_ACCESS_CODE`      | 可选家庭访问口令；未配置时是本地演示访问，不能当作真实成员权限隔离    |
| `PDF_PYTHON`           | 可选Python路径，默认检测Codex运行时，再回退到系统Python               |
| `PDF_CJK_FONT`         | 可选可嵌入的中文TTF/TTC字体路径；Mac默认检测系统黑体                  |

配置千帆后，在事件的“照护交接卡”中点击“生成交接摘要”。只有真实收到有效接口响应后，能力页才标为已验证。调用失败会记录原因并使用本地模板。默认没有任何凭证，完整事件闭环仍可使用。

百度地图 AK 配置后，工作台加载真实百度地图底图，位置点仍明确标为模拟。地图加载失败会回退到本地示意图。鹰眼围栏不在当前真实接入范围内。

手机与电脑接入同一可信 Wi-Fi 后，在“档案与连接”页查看局域网老人端地址。此 demo 有模拟身份与角色切换，不包含真实账号鉴权，请勿直接用于公网真实照护。手机端按钮操作不依赖麦克风权限；浏览器语音播放是否可用取决于设备。

## 当前功能与来源

| 功能                                    | 当前实现                                                  |
| --------------------------------------- | --------------------------------------------------------- |
| 事件规则与服务端计时                    | 实际执行；文件保存，重启恢复到期任务                      |
| 多端同步                                | HTTP 操作 + SSE 状态订阅                                  |
| 接手、进展、结案                        | 实际操作；版本校验；结案需记录医疗任务处理方式            |
| 千帆摘要与只读工具调用                  | 已实现适配；需要自己的凭证完成真实联调                    |
| 无凭证／模型失败降级                    | 本地结构化模板，明确标记来源                              |
| 老人端语音播报                          | 统一语音服务：百度 TTS／macOS 本机声音，分段预加载与真实播放回执    |
| 慢表达                                  | 按原有时间顺序演示预设续句；没有真实 ASR 或自适应端点模型 |
| 姿态、IMU、轨迹                         | 预设模拟证据，非实时模型推理                              |
| 地图                                    | 默认本地示意图；可配置百度地图 JS API GL                  |
| 通知／医疗接单                          | 应用内模拟通道与模拟回执；不发送真实短信或机构请求        |
| 昆仑芯、BCC、BOS、飞桨、小度、RTC、鹰眼 | 待适配／待接入，逐项标记                                  |

没有自动推断诊断、伤情或绝对安全。人工结案与移交有不同结果文案。没有真实人群检测准确率或增量对照实验结论。

## 演示操作

新版监控演示使用 **8秒确认、首次联络后30秒追加二级、60秒急救提示**。一级全部立即联络，三级只通报；夜间外出会提前触达全部层级。时限可在“我的”中调整，旧事件截止时间不会被重置。补充演示脚本见 [四Tab演示说明](docs/HOME_DEMO.md)。

新增「计划助手」：用自然语言创建提醒草稿，支持一次、每天、每周、工作日与相对时间；启用后由服务端计时，并在老人端或家属端展示、播报。未配置千帆时明确使用本地简易解析。详见 [计划 Agent 与语音提醒](docs/REMINDER_AGENT.md)。

新增「日常与趋势」入口：患者一键记用药、睡眠、心情与日常变化，家属补充；按照护优先级合并提醒；自动生成 7／14／30 天趋势和可导出的就诊摘要。详见 [日常照护说明](docs/DAILY_CARE.md)。用药计划默认关闭，未记录不直接判定为漏服。

详细答辩脚本见 [docs/DEMO.md](docs/DEMO.md)。

1. 从工作台启动“疑似跌倒”，查看模拟证据与确认窗口。
2. 老人端点击“需要帮助”，或在演示控制台推进 45 秒。
3. 家人点击“我来接手”，更新“已到达现场”等进展。
4. 查看交接卡、生成摘要、导出 Markdown。
5. 记录处理结果并结案；医疗任务需要明确处理。
6. 查看时间轴、实际工具记录，或导出本轮 JSON。

默认演示参数：确认 45 秒、等待接手 30 秒、进展检查 60 秒。推进时钟只修改本轮演示时间偏移，不修改已经保存的截止时间。这些参数不是真实照护时限。

上面的45秒参数保留在原演示控制台的旧场景中；新的监控入口使用独立8/30/60秒策略。两种计时都仅为演示，不是真实照护或急救标准。

## 本地存储与PDF

运行存档自动迁移为AES-256-GCM加密，密钥保存在对应的 `.key` 文件（权限600）中。必须连同密钥备份；丢失密钥无法解密。原始医疗上传文件也单独加密。HTTP/SSE和应用内存不是端到端加密，真实部署仍需HTTPS及正式身份体系。

PDF采用Python `reportlab` / `pypdf`，当前桌面运行时已具备。其他环境可安装 `requirements-pdf.txt`，并配置支持中文的TTF/TTC字体。PDF提取支持20页、5MB以内的文字PDF；图片/扫描件暂不OCR，需要转录后核对。

医生分享是24小时的只读PDF快照，可撤销。仅当 `APP_ACCESS_CODE` 已设置时，家庭API才要求登录；默认本地演示模式不提供真实成员隔离。可运行 `node scripts/smoke-access.mjs` 验证口令与分享边界。

## 实现结构

```text
src/App.jsx          页面、角色交互、SSE 订阅
src/components.jsx   地图、示意图、时间轴、确认状态
src/styles.css       响应式界面与适老化样式
src/DailyCare.jsx     患者一键记录、家属补充、分级提醒与就诊摘要
src/daily.css         日常照护页面与手机样式
shared/daily.js       共享日期、记录去重、优先级与自动汇总
server/daily.js       日常记录与提醒规则、用药窗口、样本载入
server/engine.js     事件规则、计时、联络任务、文件保存
server/agent.js      千帆适配、受控只读工具、模板降级
server/index.js      HTTP 接口、SSE、本地开发／静态服务
tests/engine.test.js  规则、恢复、并发与 Agent 降级测试
tests/daily.test.js   记录来源、静默策略、时区、风险与摘要测试
public/references/   用户提供的原始架构图
data/state.json      运行时数据，不提交到 Git
```

事件与待发送模拟任务在同一个状态快照中保存，写入临时文件后 rename 替换。单进程内顺序执行状态修改，保存失败回滚内存。该实现适合受控 demo，不等同于生产数据库事务；不支持多个写入进程或跨实例一致性。

`runId` 隔离复位前后的输入与异步结果；事件 `version` 防止并发覆盖；联络幂等键包含事件、接收人、通道和轮次。发送结果未知时需核查，避免盲目重发。

测试与构建：

```sh
npm run check
```

测试包含真实规则行为与模拟模型响应；通过测试不表示已验证百度账号权限、真实设备或真实照护效果。
